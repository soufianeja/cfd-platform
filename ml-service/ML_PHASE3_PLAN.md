## Step 3.1 — Geometry → Features Pipeline

**Goal**: Every geometry on the platform must produce a standardized set of features. This is the foundation of the entire ML pipeline.

**Trigger points** (when extraction must run):
1. On geometry upload (`.stl` or `.obj` file)
2. Before a prediction is made (if features are not cached)
3. Before a dataset row is exported for retraining

### What to build

#### [MODIFY] `app/ml/feature_builder.py`

Extend the existing `extract_features_from_stl()` to also support `.obj` files:

```python
import trimesh

SUPPORTED_FORMATS = [".stl", ".obj"]

def extract_geometry_features(file_path: str) -> dict:
    """
    Extract standardized geometry features from a 3D mesh file.
    Supports .stl and .obj formats.
    """
    mesh = trimesh.load(file_path, force='mesh')
    bounds = mesh.bounding_box.extents  # [length, width, height]

    return {
        "surface_area":  round(float(mesh.area), 6),
        "volume":        round(float(abs(mesh.volume)), 6),
        "length":        round(float(bounds[0]), 6),
        "width":         round(float(bounds[1]), 6),
        "height":        round(float(bounds[2]), 6),
        "frontal_area":  round(float(bounds[1] * bounds[2]), 6),
        # Derived
        "aspect_ratio":  round(float(bounds[0] / bounds[1]), 6) if bounds[1] > 0 else 0,
    }
```

#### Where features are stored

After extraction, features are stored in the database (via Laravel) in the geometry's associated record. This avoids re-extracting features on every prediction request.

**Database columns to add** (migration in Laravel):
```

```

## Step 3.2 — Unified Feature Builder

**Goal**: One single function converts geometry features + simulation parameters into the ML input vector. This function must be used identically in both training and prediction to avoid train/predict mismatch.

### What to build / modify

#### [MODIFY] `app/ml/feature_builder.py`

Add the `build_features()` function below `extract_geometry_features()`:

```python
FEATURE_ORDER = [
    "surface_area",
    "volume",
    "length",
    "width",
    "height",
    "frontal_area",
    "velocity",
    "reynolds",
    "rear_wing_angle",   # FSAE-specific (0 for others)
    "slant_angle",       # Ahmed body-specific (0 for others)
]

def build_features(geometry_features: dict, simulation_params: dict) -> list:
    """
    Merge geometry + simulation parameters into an ordered ML input vector.
    Missing keys default to 0. Order must match training column order.
    """
    combined = {**geometry_features, **simulation_params}
    return [combined.get(key, 0) for key in FEATURE_ORDER]
```

### Rules

| Rule | Detail |
|------|--------|
| Missing optional values | Default to `0` (not `None`) |
| `FEATURE_ORDER` is the contract | Any change here requires model retraining |
| Used in `train.py` and `predict.py` | Never build the vector inline — always call `build_features()` |

**Verification**: Call `build_features()` with a partial dict and confirm it returns a 10-element list with zeros for missing keys.

## Step 3.3 — Validated Simulation → Dataset Row

**Goal**: Every simulation that researchers mark as validated (accurate results) contributes one row to the ML training dataset. This turns the platform into a data generator.

### What to build

#### [NEW] `app/ml/dataset_builder.py`

```python
import csv, os
from datetime import datetime

DATASET_PATH = "datasets/real_simulations.csv"

HEADERS = [
    "surface_area", "volume", "length", "width", "height", "frontal_area",
    "velocity", "reynolds", "rear_wing_angle", "slant_angle",
    "drag", "lift",
    "geometry_type", "validated_at",
]

def append_simulation_row(geometry_features: dict, simulation_params: dict,
                           cd: float, cl: float, geometry_type: str):
    """
    Append one validated simulation result to the real dataset CSV.
    Called from the Laravel backend via the /dataset/append endpoint.
    """
    row = {
        **geometry_features,
        **simulation_params,
        "drag":          cd,
        "lift":          cl,
        "geometry_type": geometry_type,
        "validated_at":  datetime.utcnow().isoformat(),
    }

    file_exists = os.path.isfile(DATASET_PATH)
    with open(DATASET_PATH, "a", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=HEADERS, extrasaction='ignore')
        if not file_exists:
            writer.writeheader()
        writer.writerow(row)

def get_dataset_size() -> int:
    if not os.path.isfile(DATASET_PATH):
        return 0
    with open(DATASET_PATH) as f:
        return sum(1 for _ in f) - 1  # subtract header
```

#### [NEW] `app/api/v1/endpoints/dataset.py`

```python
from fastapi import APIRouter, HTTPException, Header
from pydantic import BaseModel
from app.core.config import settings
from app.ml.dataset_builder import append_simulation_row, get_dataset_size

router = APIRouter()

class SimulationRow(BaseModel):
    geometry_type: str
    geometry_features: dict
    simulation_params: dict
    drag_coefficient: float
    lift_coefficient: float

@router.post("/append")
async def append_row(data: SimulationRow, x_api_key: str = Header(...)):
    if x_api_key != settings.TRAINING_API_KEY:
        raise HTTPException(status_code=403, detail="Unauthorized")

    append_simulation_row(
        geometry_features=data.geometry_features,
        simulation_params=data.simulation_params,
        cd=data.drag_coefficient,
        cl=data.lift_coefficient,
        geometry_type=data.geometry_type,
    )
    return {"status": "appended", "dataset_size": get_dataset_size()}

@router.get("/size")
async def dataset_size():
    return {"size": get_dataset_size()}
```

## Step 3.4 — Auto-Retraining Trigger

**Goal**: When enough new validated simulations accumulate, retraining is triggered automatically — no manual intervention needed.

### Strategy

```
After every /dataset/append call:
    if dataset_size >= RETRAIN_THRESHOLD:
        trigger retraining (background task)
```

### What to build / modify

#### [MODIFY] `.env` / `.env.example`

```
RETRAIN_THRESHOLD=50   # Retrain when 50+ new validated samples exist
```

#### [MODIFY] `app/api/v1/endpoints/dataset.py`

After appending, check if threshold is reached and trigger retraining as a background task:

```python
from fastapi import BackgroundTasks
from app.ml import train as ml_train
from app.core.config import settings

@router.post("/append")
async def append_row(data: SimulationRow, x_api_key: str = Header(...),
                     background_tasks: BackgroundTasks = None):
    if x_api_key != settings.TRAINING_API_KEY:
        raise HTTPException(status_code=403, detail="Unauthorized")

    append_simulation_row(...)
    size = get_dataset_size()

    if size >= settings.RETRAIN_THRESHOLD:
        background_tasks.add_task(ml_train.train_models)

    return {"status": "appended", "dataset_size": size,
            "retraining_triggered": size >= settings.RETRAIN_THRESHOLD}
```

**Retraining flow**:
```
POST /dataset/append (validated simulation)
         ↓
dataset_size >= RETRAIN_THRESHOLD?
    YES → background task: train_models()
    NO  → return immediately
         ↓
New cd_model.pkl + cl_model.pkl saved
         ↓
model_version incremented
         ↓
Next prediction uses updated models
```

**Verification**: Append rows until threshold is crossed and verify that new `.pkl` files have a newer modification timestamp.

## Step 3.5 — Model Versioning & Metrics Tracking

**Goal**: Keep a record of every training run — version, date, dataset size, and accuracy metrics — so model evolution can be tracked.

### What to build / modify

#### [MODIFY] `app/ml/train.py`

After training, write a `model_info.json` file:

```python
import json
from datetime import datetime

def save_model_info(cd_metrics: dict, cl_metrics: dict, dataset_size: int):
    info = {
        "model_version":  get_next_version(),
        "training_date":  datetime.utcnow().isoformat(),
        "dataset_size":   dataset_size,
        "cd_model": {
            "mae":  cd_metrics["mae"],
            "rmse": cd_metrics["rmse"],
            "r2":   cd_metrics["r2"],
        },
        "cl_model": {
            "mae":  cl_metrics["mae"],
            "rmse": cl_metrics["rmse"],
            "r2":   cl_metrics["r2"],
        },
    }
    with open("models/model_info.json", "w") as f:
        json.dump(info, f, indent=2)

def get_model_info() -> dict:
    try:
        with open("models/model_info.json") as f:
            return json.load(f)
    except FileNotFoundError:
        return {"error": "No model info available. Run training first."}
```

```
Raw Geometry (.stl/.obj)
       ↓
Structured Feature Vector (build_features)
       ↓

       ↓
Fast Prediction: Cd + Cl
       ↓
Validated Simulation → Dataset → Retraining → Better Model
```

**Key concept**:
- **CFD simulations** = ground truth
- **ML model** = fast approximation for early-stage design
- **The platform** = a data generator and continuously improving learning system
